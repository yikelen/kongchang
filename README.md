## 它解决什么问题

现场常见做法是：PPT 在一块屏翻页，音视频另开播放器——容易播错、切错屏、讲话时垫乐盖过人声。

**简易控场**把「节目单 + 点播库 + 播放 + 投影」收成一个 Windows 小工具：

- 操作台在一块屏，视频全屏投到另一块屏
- **不控制 PPT 翻页**（PPT 仍由你自己播，通常在另一台电脑或另一块屏）
- 音视频用自带 **mpv** 解码，程序只负责控场逻辑
- 左侧 **节目单** 按议程手动走；右侧 **素材库** 随时点播（过场、颁奖、茶歇、采访）

适合：**年会 / 晚会**、**培训 / 宣讲**、**启动会 / 动员会** 等「一块屏翻课件、另一块屏出片」的现场。

仅 **Windows 10/11 x64**。当前源码版本见 `src/__init__.py`（与 GitHub Release 标签一致，例如 `v0.2.4`）。

## 两路怎么播

这是现场最容易混的地方。软件是 **两路独立通道**，不是一个播放器里的两个列表。

| | 节目单（左） | 素材库（右） |
|--|-------------|--------------|
| 用途 | 这场会的正式顺序 | 随时点播：过场、颁奖、茶歇、采访、应急 |
| 怎么走 | **只手动**：上一条 / 下一条 / 播放。播完 **不停也不切下一条** | 点哪条播哪条。分类可设单曲 / 顺序 / 列表循环 |
| 视频 | 先 **预览**（操作台小窗暂停）→ **播放** → **全屏** | **没有预览**。点另一条即切播；已全屏就接着全屏 |
| 音频 | 与本路视频互斥：同时只出一条 | 可叠在 **无声视频** 上（视频轨会静音） |
| 停止 | 底栏「停止」：本路音频渐停（约 1.6 秒）+ 本路视频立刻停 | 「停止」停素材库声画；叠播时可用「停音频 / 停视频」只停一路 |
| 音量 | 底栏滑条（本机记住） | 素材库进度条右侧滑条（与底栏独立） |

**互斥 / 叠播（当前实现）：**

- **全场同时只一个视频**（节目单和素材库共用一个视频播放器）
- **节目单音频 ↔ 素材库音频互斥**（两路音乐不会叠在一起）
- **节目单自己的音视频互斥**（点节目单视频会停节目单音频，反之亦然）
- **可以叠播的组合**：任意一路视频 + **素材库音频**（视频静音，垫乐单独走）
- 节目单里的音视频会自动出现在素材库最底下的分类 **「默认」**，顺序与节目单一致，方便拿同一条垫乐去叠无声片。不要在「默认」里手排节目单副本。

**全停：** 底栏「全停」或 `Ctrl+Esc`，节目单和素材库声画立刻全停（不做渐停）。焦点在素材库时按 `Esc` 只停素材库；否则等同全停。

**压低音频：** 讲话时点「压低音频」或按 `D`。约 0.9 秒把 **当前正在出的那路音频** 渐变到设定音量的 **60%**，再按渐变恢复。不是停止，也不是瞬间跳音量。

**封面：** 视频不循环播完会落到封面图（没设封面就是黑场）。菜单 **工程 → 设置封面图…**。也可随时点「封面 / 黑场」。

**分类播放（只作用于素材库、且只在同一分类、同一类型里切）：**

| 分类头按钮 | 行为 |
|------------|------|
| **默认** | 选中谁播谁。勾了该条循环就单曲循环，没勾就播完停，不自动下一首 |
| **单曲** | 当前条循环 |
| **顺序** | 同分类、同类型播完切下一首，到末尾停 |
| **列表** | 同分类、同类型列表循环（采访轮播用这个） |

音频、视频各切各的；叠播时互不影响。节目单 **没有** 这套自动切歌。

为避免误触：**没有双击播放**。单击选中，再点播放（或空格）。

| **帮助** | 使用说明 `F1`、快捷键、检查更新、关于 |
| **全屏投影到**（右上角） | 列出显示器，标「本软件」；不要选盖住操作台的那块屏 |

**检查更新：** 若本夹是 git 克隆，会对照 GitHub `origin/main`，确认后只拉源码（不重下 Python/mpv，不动 `data` 和工程 json）。便携 zip 安装则会打开 [Releases](https://github.com/yikelen/kongchang/releases/latest)。也可双击 `从GitHub更新.bat`。

### 节目单（左侧）

| 功能 | 说明 |
|------|------|
| 三种条目 | **音频** / **视频** / **备注**（备注只作提词，主按钮为灰，不可播） |

| 正在播高亮 | 播放中黄色，选中绿色；底栏卡片同步显示 |
| 不自动下一条 | 播完停在当前条，由人点「下一条」再播 |
| 自动保存 | 改单后约 1.5 秒落盘 |

| 功能 | 说明 |
|------|------|
| 名称 / 备注 | 改显示名与现场口令（如 PPT 页码、串词） |
| 浏览媒体… | 选文件，路径按相对工程目录保存 |
| 音频循环 / 视频循环 | 音频默认勾选循环；视频默认否。素材库分类若已切到单曲/顺序/列表，本勾选暂时无效 |

## 典型使用场景

下面几个场景都假设：**操作台一块屏跑本软件，观众屏投视频；PPT 另开，不由本软件翻页。**

### 1. 年会 / 晚会

**现场目标：** 开场片、节目过场、颁奖垫乐、茶歇背景乐，顺序清楚、临时加一首也不乱。

**怎么排：**

1. 左侧节目单按流程写死：备注「【待命】」→ 暖场音频 → 开场视频 → 各节目备注（写主持人串词）→ 颁奖视频 → 散场音频  
2. 右侧素材库按分类备货：`过场`、`颁奖`、`茶歇`（领导突然加环节时从这里点播）  
3. 开场前把 **全屏投影到** 选成「推荐」屏；开场片先 **预览** 看一眼，再 **播放**  
4. 颁奖间隙：节目单停住，右侧点一首颁奖垫乐；讲话时点 **压低音频** 或 **停止**（渐停），避免盖过人声  

**素材库典型用法：** 主持人说「请下一位上台」时多拖了 20 秒——用过场乐顶住，不必改节目单。

### 2. 培训 / 宣讲

**现场目标：** 课件翻页自己控，偶尔插一段讲解视频或案例短片，其余时间安静。

**怎么排：**

1. 节目单以 **备注** 为主，`备注` 列写清「PPT 第 N 页 / 讲什么」  
2. 需要出片的地方插 **视频** 条（path 指向短片）；讲解间隙可放一条很短的 **音频** 过场  
3. 右侧只留少量「应急」：如答疑等待垫乐、网络卡顿时的静音片  
4. 讲到该页：选中对应视频 → **预览** 确认 → **播放** 全屏；讲完 **收起全屏** 或 **Esc**，回到课件  

**注意：** 讲话段落不要垫乐；备注条本身不能播，只是提词，避免误点。

### 3. 启动会 / 动员会

**现场目标：** 国歌 / 司歌、暖场、VCR、领导致辞前后过场，流程固定、容错要高。

**怎么排：**

1. 节目单按议程顺序：待命备注 → 暖场音频（循环）→ 国歌/司歌视频或音频 → 开场 VCR → 「致辞」备注（纯静音）→ 过场 → 结束垫乐  
2. 国歌、VCR 等关键节点：**先预览、再播放**；致辞备注行选中后主按钮为灰，防止误开声  
3. 右侧备：`暖场备用`、`过场`、`应急视频`——领导改稿、等人时从素材库补  
4. 无声 VCR 需要气氛时：节目单或素材库播视频，再在 **素材库** 点一首音频（叠播会自动静音视频轨）  

**复盘建议：** 会后把当天用到的素材库条目整理进节目单，下次直接打开同一份 json。

### 4. 同一台电脑的双屏习惯（各场景通用）

| 步骤 | 做什么 |
|------|--------|
| 1 | 扩展桌面：操作台屏开控场 + PPT 备注；观众屏只给全屏视频 |
| 2 | 本软件右上角选 **「推荐」** 那块屏（不要选标「本软件」的） |
| 3 | PPT 全屏到操作台或单独一屏，**不要**和本软件抢同一块观众屏 |
| 4 | 先打开本场 `活动.json`，走一遍预览，再进场 |

## 安装

### 方式 A：便携包（推荐，免装 Python）

1. 打开 [Releases](https://github.com/yikelen/kongchang/releases/latest)
2. 下载 `kongchang-windows-portable-*.zip` 并解压到本地盘（如 `D:\kongchang`）
3. 双击 **`启动.bat`**

## 工程文件格式

一份工程 = **一个文件夹 + 一份 json**（文件名可用中文）：

```text
2026年会/
  2026年会.json
  audio/
    warmup.mp3
  video/
    opening.mp4
  cover.png
```

`path` 相对 **json 所在目录**。音视频可暂空 path（列表标「缺文件」）。备注条不要 path。

最小示例：

```json
{
  "version": 1,
  "cues": [
    { "type": "note", "name": "【待命】会前", "notes": "等入场" },
    { "type": "audio", "name": "暖场", "notes": "PPT p1", "path": "audio/warmup.mp3" },
    { "type": "video", "name": "开场片", "notes": "全屏", "path": "video/opening.mp4", "loop": false }
  ],
  "library": [
    { "type": "audio", "name": "过场垫", "category": "过场", "path": "audio/bridge.mp3", "loop": true }
  ],
  "hold_cover": "cover.png",
  "library_play_modes": { "采访": "repeat_all" }
}
```

软件打开后会把 `cues` 里的音视频 **自动镜像** 到素材库分类「默认」（写入 `source_id`）。生成 json 时 **不要手写 `source_id`，也不要往「默认」里抄一份节目单。**

更多容错规则与给 AI 的提示词见 [`AGENTS.md`](AGENTS.md)。

<details>
<summary><b>JSON 字段与容错（点击展开）</b></summary>

| 字段 | 必填 | 说明 |
|------|------|------|
| `version` | 否 | 现为 `1` |
| `type` | 是 | `audio` / `video` / `note`（也可用中文「音频 / 视频 / 备注」） |
| `name` | 建议 | 列表显示名 |
| `notes` | 否 | 现场口令、PPT 页码 |
| `path` | 否 | 相对 json 的媒体路径；反斜杠会转成正斜杠 |
| `loop` | 否 | 音频默认循环；视频默认否 |
| `category` | 否 | 素材库分类（`library` 条目常用）。节目单镜像固定为「默认」 |
| `index` / `id` | 否 | 可省略，软件会补。有 `index` 则按它排序 |
| `trim_in` / `trim_out` | 否 | 秒；0 或不写 = 不裁 |
| `fade_in` / `fade_out` | 否 | 秒；0 或不写 = 用软件默认渐强 / 约 1.6 秒渐停 |
| `hold_cover` | 否 | 工程级封面图，相对 json |
| `library_play_modes` | 否 | 按分类：`default` / `repeat_one` / `sequence` / `repeat_all`（也可用中文 默认/单曲/顺序/列表） |
| `source_id` | 否 | 仅软件写入，把素材库镜像指回节目单条目。人工不要填 |
| `readme` | 否 | 软件保存时会写一段说明；可忽略 |

- `cues`：节目单，按数组从上到下。**播放不会自动前进**  
- `library`：素材库，不进节目单顺序  
- 多写的字段会忽略；旧工程仍能打开  

</details>

## 技术架构

```text
kongchang/
  启动.bat                      闪屏 + 启动 GUI
  从GitHub更新.bat              git pull origin/main（不动 vendor / data）
  创建桌面快捷方式.bat
  一键准备运行环境.bat          首次下载 vendor
  环境检测.bat
  vendor/python/                便携 CPython + PySide6（发行包装有；源码仓用脚本下载）
  vendor/mpv/                   便携 mpv
  examples/demo_show.json       文字演示
  src/                          源码（PySide6 UI + mpv IPC）
  tests/test_playback_logic.py  分类循环 / 镜像 / 互斥等单测
  AGENTS.md                     Agent 安装与改代码约定
  .github/workflows/portable.yml  推送 v* 标签时打 Windows 便携 zip
```

- 工程：`*.json`（跟活动走）  
- 本机设置：`data/settings.json`（投影屏、主题、音量、最近打开等，不进 Git）  
- 播放：进程只发 IPC；解码与窗口由 `mpv.exe` 完成。节目单音频、素材库音频是两个 mpv 进程，视频全场共用一个  
- 单实例：再开一次会唤起已有窗口，不会起第二份  

跑单测（需已有 `vendor\python`）：

```bat
vendor\python\python.exe -m unittest tests.test_playback_logic
```
