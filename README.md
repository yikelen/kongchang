## 它解决什么问题

现场常见做法是：PPT 在一块屏翻页，音视频另开播放器——容易播错、切错屏、讲话时垫乐盖过人声。

**简易控场**把「节目单 + 播放 + 投影」收成一个 Windows 小工具：

- 操作台在一块屏，视频全屏投到另一块屏
- **不控制 PPT 翻页**（PPT 仍由你自己播）
- 音视频用自带 **mpv** 解码，程序只负责控场逻辑

适合：**年会 / 晚会**、**培训 / 宣讲**、**启动会 / 动员会** 等「一块屏翻课件、另一块屏出片」的现场。

## 功能特性

> 以下说明均对照当前源码菜单与按钮；若与界面不一致，以软件界面为准。

### ① 菜单栏

| 菜单 / 控件 | 说明 |
|-------------|------|
| **工程 → 新建…** | `Ctrl+N`，另存一份新的 `.json` |
| **工程 → 打开 / 导入…** | `Ctrl+O`，打开已有工程 |
| **工程 → 保存** | `Ctrl+S`；平时改单也会约 1.5 秒自动保存 |
| **工程 → 另存为…** | 复制出另一份工程文件 |
| **工程 → 最近打开** | 快捷再开；可清空记录 |
| **工程 → 检查媒体…** | `Ctrl+K`，列出找不到文件的条目 |
| **工程 → 设置封面图…** | 视频播完落到这张图；没设则黑场 |
| **工程 → 锁定节目单** | `Ctrl+L`，不能改顺序，仍能播 |
| **工程 → 演出模式** | `F11`，收起中间编辑栏 |
| **工程 → 打开演出日志** | 每次播放/停止的时间记录 |
| **工程 → 退出** | 有未保存改动会询问 |
| **音频输出** | 选声卡；换设备会重拉播放器 |
| **主题** | **黑色** / **白色** |
| **帮助** | 使用说明 `F1`、快捷键、检查更新、关于 |
| **全屏投影到**（右上角） | 列出显示器，标「本软件」；不要选盖住操作台的那块屏 |

### ②③ 节目单（左侧）

| 功能 | 说明 |
|------|------|
| 三种条目 | **音频** / **视频** / **备注**（备注只作提词，主按钮为灰，不可播） |
| 添加 / 删除 | 顶栏 `+ 音频` `+ 视频` `+ 备注`、`删除` |
| 拖拽排序 | 在列表内拖行调整顺序（无单独「上移 / 下移」按钮） |
| 缺文件提示 | 媒体还没拷齐也能先排单，名称旁标「缺文件」 |
| 正在播高亮 | 播放中黄色，选中绿色；底栏「正在播」卡片同步显示 |
| 自动保存 | 改单后约 1.5 秒落盘 |

### 编辑选中（中栏）

| 功能 | 说明 |
|------|------|
| 名称 / 备注 | 改显示名与现场口令（如 PPT 页码） |
| 浏览媒体… | 选文件，路径按相对工程目录保存 |
| 音频循环 / 视频循环 | 音频默认勾选循环；视频默认否 |
| 分类（仅素材库） | 下拉切换；`编辑` 改分类名；`+` 新建分类 |

### 底栏主播放（只跟节目单）

| 功能 | 说明 |
|------|------|
| 上一条 / 下一条 | 在节目单里移动选中行 |
| 预览 → 播放 | 视频先出预监小窗（暂停），确认后再点播放投屏 |
| 停止 | **渐停** 后结束（节目单通道） |
| 暂停 / 继续 | 暂停时按钮文案变为「继续」 |
| 全屏 / 收起全屏 | 投到「全屏投影到」所选屏；可收回预监 |
| 全停 | 节目单和素材库声画一起停（`Ctrl+Esc`） |
| 静音 / 封面 / 压低音频 | 全部声道静音；切封面或黑场；垫乐渐变到 60% |
| 进度 / 音量 | 可拖进度；音量本机记住 |

主按钮会随选中条目变化：

| 选中状态 | 绿色主按钮 | 含义 |
|----------|------------|------|
| 备注 | 播放（灰） | 不可播 |
| 视频未预监 | **预览** | 小窗暂停，不投屏 |
| 视频已预监 | **播放** | 开播到投影屏 |
| 正在播 | 播放中 | — |
| 已暂停 | 重新播放 | 旁侧「继续」接着播 |

键盘（控场窗焦点、且未在输入框内）：

| 键 | 作用 |
|----|------|
| `Space` | 播放当前选中（节目单或素材库，看焦点） |
| `P` | 暂停 / 继续 |
| `←` / `→` | 进度 ±5 秒 |
| `↑` / `↓` | 音量 ±5 |
| `M` / `B` / `D` | 静音 / 封面 / 压低音频 |
| `Esc` | 素材库焦点停素材库；否则全停 |
| `Ctrl+Esc` | 全停 |
| `F11` | 演出模式 |
| `1–9` | 演出模式下点播素材库可见第 n 条 |

### 素材库（右侧，与节目单独立）

| 功能 | 说明 |
|------|------|
| 音视频同表 | `+ 音频` / `+ 视频`；搜索；按分类分组 |
| 分类播放 | 分类头按钮：默认 / 单曲 / 顺序 / 列表循环 |
| 独立播放条 | 播放 / 停止 / 暂停 / 全屏 / 收起全屏；叠播时另有 `停音频` / `停视频` |
| 音频可叠视频 | 无声片可垫乐；叠播时暂静音视频轨 |
| 视频全局互斥 | 节目单与素材库同时只播一个视频 |
| 默认分类 | 节目单音视频自动镜像到最底下的「默认」，顺序与节目单一致 |
| 删除 | 焦点在素材库时按 `Delete`，确认后删除 |

### 工程与 AI

| 功能 | 说明 |
|------|------|
| JSON 工程 | 一份 `活动名.json` + 相对路径媒体即可带走 |
| 可给 AI 生成 | 字段少、容错；见 [工程文件格式](#工程文件格式) 与 [`AGENTS.md`](AGENTS.md) |

## 典型使用场景

下面几个场景都假设：**操作台一块屏跑本软件，观众屏投视频；PPT 另开，不由本软件翻页。**

### 1. 年会 / 晚会

**现场目标：** 开场片、节目过场、颁奖垫乐、茶歇背景乐，顺序清楚、临时加一首也不乱。

**怎么排：**

1. 左侧节目单按流程写死：备注「【待命】」→ 暖场音频 → 开场视频 → 各节目备注（写主持人串词）→ 颁奖视频 → 散场音频  
2. 右侧素材库按分类备货：`过场`、`颁奖`、`茶歇`（领导突然加环节时从这里点播）  
3. 开场前把 **全屏投影到** 选成「推荐」屏；开场片先 **预览** 看一眼，再 **播放**  
4. 颁奖间隙：节目单停住，右侧点一首颁奖垫乐；讲话时点 **停止**（渐停），避免盖过人声  

**素材库典型用法：** 主持人说「请下一位上台」时多拖了 20 秒——用过场乐顶住，不必改节目单。

### 2. 培训 / 宣讲

**现场目标：** 课件翻页自己控，偶尔插一段讲解视频或案例短片，其余时间安静。

**怎么排：**

1. 节目单以 **备注** 为主，`备注` 列写清「PPT 第 N 页 / 讲什么」  
2. 需要出片的地方插 **视频** 条（path 指向短片）；讲解间隙可放一条很短的 **音频** 过场  
3. 右侧只留少量「应急」：如答疑等待垫乐、网络卡顿时的静音片  
4. 讲到该页：选中对应视频 → **预览** 确认 → **播放** 全屏；讲完 **收起全屏** 或 **Esc**，回到课件  

**注意：** 讲话段落不要垫乐；备注条本身不能播，只是提词，避免误点。

### 3. 启动会 / 动员会

**现场目标：** 国歌 / 司歌、暖场、VCR、领导致辞前后过场，流程固定、容错要高。

**怎么排：**

1. 节目单按议程顺序：待命备注 → 暖场音频（循环）→ 国歌/司歌视频或音频 → 开场 VCR → 「致辞」备注（纯静音）→ 过场 → 结束垫乐  
2. 国歌、VCR 等关键节点：**先预览、再播放**；致辞备注行选中后主按钮为灰，防止误开声  
3. 右侧备：`暖场备用`、`过场`、`应急视频`——领导改稿、等人时从素材库补  
4. 无声 VCR 需要气氛时：节目单播视频，右侧再播临时音频（叠播会自动压低视频声轨）  

**复盘建议：** 会后把当天用到的临时条目整理进节目单，下次直接打开同一份 json。

### 4. 同一台电脑的双屏习惯（各场景通用）

| 步骤 | 做什么 |
|------|--------|
| 1 | 扩展桌面：操作台屏开控场 + PPT 备注；观众屏只给全屏视频 |
| 2 | 本软件右上角选 **「推荐」** 那块屏（不要选标「本软件」的） |
| 3 | PPT 全屏到操作台或单独一屏，**不要**和本软件抢同一块观众屏 |
| 4 | 先打开本场 `活动.json`，走一遍预览，再进场 |

## 安装

### 方式 A：便携包（推荐，免装 Python）

1. 打开 [Releases](https://github.com/yikelen/kongchang/releases/latest)
2. 下载 `kongchang-windows-portable-*.zip` 并解压到本地盘（如 `D:\kongchang`）
3. 双击 **`启动.bat`**

若提示 Qt / DLL 错误，先安装 [VC++ 2015–2022 x64](https://aka.ms/vs/17/release/vc_redist.x64.exe) 再开。

### 方式 B：从源码克隆

仓库不含 `vendor`（约 350MB）。需要本机有 **Python 3.11+** 仅用于首次下载：

```bat
git clone https://github.com/yikelen/kongchang.git
cd kongchang
一键准备运行环境.bat
启动.bat
```

或无人值守（给 Agent）：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\agent_bootstrap.ps1
.\启动.bat
```

## 工程文件格式

一份工程 = **一个文件夹 + 一份 json**（文件名可用中文）：

```text
2026年会/
  2026年会.json
  audio/
    warmup.mp3
  video/
    opening.mp4
```

`path` 相对 **json 所在目录**。音视频可暂空 path（列表标「缺文件」）。备注条不要 path。

最小示例：

```json
{
  "version": 1,
  "cues": [
    { "type": "note", "name": "【待命】会前", "notes": "等入场" },
    { "type": "audio", "name": "暖场", "notes": "PPT p1", "path": "audio/warmup.mp3" },
    { "type": "video", "name": "开场片", "notes": "全屏", "path": "video/opening.mp4", "loop": false }
  ],
  "library": [
    { "type": "audio", "name": "过场垫", "category": "过场", "path": "audio/bridge.mp3", "loop": true }
  ]
}
```

更多字段说明、容错规则、给 AI 的提示词模板见下方折叠内容与 [`AGENTS.md`](AGENTS.md)。

<details>
<summary><b>JSON 字段与容错（点击展开）</b></summary>

| 字段 | 必填 | 说明 |
|------|------|------|
| `type` | 是 | `audio` / `video` / `note`（也可用中文「音频 / 视频 / 备注」） |
| `name` | 建议 | 列表显示名 |
| `notes` | 否 | 现场口令、PPT 页码 |
| `path` | 否 | 相对 json 的媒体路径 |
| `loop` | 否 | 音频默认循环；视频默认否 |
| `category` | 否 | 素材库分类（`library` 条目常用） |
| `index` / `id` | 否 | 可省略，软件会补 |

- `cues`：节目单，按数组从上到下  
- `library`：素材库，不进节目单顺序  
- 路径反斜杠会转成正斜杠；多写的字段会忽略  

</details>

## 技术架构

```text
kongchang/
  启动.bat                 闪屏 + 启动 GUI
  vendor/python/           便携 CPython + PySide6（发行包装有；源码仓用脚本下载）
  vendor/mpv/              便携 mpv
  examples/demo_show.json  文字演示
  src/                     源码（PySide6 UI + mpv IPC）
  AGENTS.md                Agent 安装协议
```

- 工程：`*.json`（跟活动走）  
- 本机设置：`data/settings.json`（投影屏、主题、最近打开等，不进 Git）  
- 播放：进程只发 IPC；解码与窗口由 `mpv.exe` 完成
